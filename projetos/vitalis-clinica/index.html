Conexão com WhatsApp

Demonstração

Este protótipo simula conversas de WhatsApp para validar o design. Para conectar o número real da clínica, escolha um provedor de API do WhatsApp Business:

Meta Cloud API (oficial)
Direto com a Meta. Gratuito até certo volume, exige verificação da empresa.
Twilio WhatsApp API
Integração facilitada, cobrança por mensagem, boa documentação.
Z-API / provedores não oficiais
Configuração rápida via QR code, sem verificação de empresa — maior risco de bloqueio.

Prescrição digital

Demonstração

O botão "Receitar" já existe no protótipo, mas hoje só simula o fluxo. Para prescrição e assinatura digital de verdade, a integração indicada é com a Memed:

Memed — prescrição eletrônica
Banco de medicamentos, alertas de interação e assinatura digital com validade legal. Requer que a clínica se torne parceira e que a médica tenha conta própria na Memed.

Notas fiscais (NFS-e)

Demonstração

Em Financeiro → Notas fiscais, a clínica já consegue montar o rascunho de uma NFS-e (nota de serviço). A emissão oficial, com numeração e validade fiscal de verdade, depende de uma integração — duas rotas possíveis:

NFS-e Nacional (gov.br/nfse)
Sistema público unificado, mantido pelo governo federal em conjunto com os municípios. Tem API própria, mas a adesão ainda está em rollout progressivo — depende do município da clínica já ter migrado.
Provedores privados (Focus NFe, eNotas, PlugNotas...)
APIs comerciais que já abstraem as regras de cada município. Caminho mais rápido hoje; exige certificado digital A1 da clínica (e-CNPJ) e plano pago por volume de notas.
