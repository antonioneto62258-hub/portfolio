# Antonio Neto — Portfólio & Currículo

Site pessoal de portfólio e currículo: Analista de Dados & BI e especialista em IA e desenvolvimento de sistemas com vibecoding.

## Estrutura

```
index.html              página principal (sobre, formação, projetos, contato)
css/style.css           estilos
js/script.js            menu mobile
assets/img/             imagens
assets/pdf/             currículo em PDF
projetos/                uma subpasta por projeto (case study ou demo ao vivo)
```

## Publicar no GitHub Pages

1. Em **Settings → Pages**, defina *Source* como `Deploy from a branch`, branch `main`, pasta `/ (root)`.
2. O site fica disponível em `https://antonioneto62258-hub.github.io/portfolio/`.
